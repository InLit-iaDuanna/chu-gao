## 已完成的适配

保留 V2 材料分类、相关段落打包、上下文清单、唯一终稿包及哈希、三格式共享语义树、

本地补充修复：

- 旧研究使用“整理旧版并制作”创建新任务，不修改旧报告；递归复用同项目、同所有者的证据版本。
  版本环和超过 16 层的链被拒绝；在途子版本使用的祖先材料受保留期保护。
- 指定竞品优先进入首批搜索，避免预算被通用词查询先用完。
- 新调用事件即时更新计数，重复事件不重复累计。
- Responses 网关把 system/developer 指导传为顶层 instructions，保留工具调用与推理续接信息。
  这是兼容调整，不宣称已证明此前正文偏离完全由此引起。
- 研究与整理阶段明确只输出研究正文，不生成代码或假称附件。
- 提案先读同版本字段投影；假设 claim 的原文和依据都必须精确匹配冻结版本。
- PPT 按实际内容为论据状态列分配宽度；仍放不下时明确拒绝，不缩小字号或删掉依据。
- 文件工具成功后校验实际清单并结束，避免完成后的多余模型回合；模型 fallback 明确失败而非误报缺清单。
- 研究 HTML 使用 DOM 清理、无权限 sandbox 和禁止脚本/联网的 CSP；片段链接改为 about:srcdoc，
  不再意外跳转到主应用地址。

## 复跑入口

```sh
node scripts/test-research.mjs
CHUGAO_REPLAY_PYTHON="$PWD/scripts/research-python.mjs" node --import tsx validation/cross-language-proposal.mjs
node --import tsx validation/replay-quality-evidence.mjs
docker compose -f docker-compose.research.yml build
docker compose -f docker-compose.research.yml up -d --no-build
```

真实验收脚本必须显式指定授权档位，并使用 `.data/research` 中原 state 继续。
不要删除 state 后用同一授权重开。当前 30 次档位为 `--authorized-v2-original-30`，固定 medium，
`--retry` 仅恢复未完成阶段，并继续受该任务累计上限限制。
`--audit-only` 只导出当前文件、版本和阶段检查，不创建任务、不调用模型、不自动重试。
